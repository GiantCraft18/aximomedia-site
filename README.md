## 🚀 Публикация сайта на GitHub Pages

Чтобы опубликовать сайт в интернете, выполни следующие действия:

**1. Создание репозитория**

- Открой [GitHub](https://github.com/).
- Создай новый публичный репозиторий.
- Название: `aximomedia-site`.

**2. Загрузка файлов**

- Открой созданный репозиторий.
- Загрузи файл `index.html` в корневую папку репозитория.

**3. Настройка GitHub Pages**

Перейди в:

`Settings → Pages`

В разделе **Build and deployment** установи:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`

Нажми **Save**.

**4. Публикация**

Подожди несколько минут. После завершения публикации GitHub предоставит ссылку на твой сайт.
